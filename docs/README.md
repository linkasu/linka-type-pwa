# Project Docs

This folder documents the LINKa Type PWA v2. It is written to help AI agents understand the system quickly and make safe changes.

## What the app does
- PWA for people with speech impairments to type text and speak it via TTS
- Quick phrases ("quickes") for one-tap speech
- Phrase bank with categories and statements
- Full-screen spotlight and reader modes
- Offline-first behavior with IndexedDB cache and queued sync

## Doc map
- `docs/architecture.md` - system structure and runtime flow
- `docs/data-models.md` - entities, relationships, and normalization
- `docs/state-and-offline.md` - Pinia stores, cache, and offline queue
- `docs/ui-flows.md` - pages, layouts, and major components
- `docs/ui-style-standards.md` - visual standards and UI style decisions
- `docs/api.md` - API client and server proxy behavior
- `docs/analytics.md` - consent-first desktop telemetry and closed outcome contract
- `docs/development.md` - local dev, env vars, and scripts
